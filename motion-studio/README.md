# Motion Studio

Motion-graphics videos made in code, for Extreme Home Lighting and the TikTok account.
Nothing here is generated by an AI video model: every frame is painted by a web page,
captured in Chrome and stitched with ffmpeg, so a video costs nothing to render.

Three parts, set up once:

| 1 · Render engine | 2 · Reference + assets | 3 · Self-critique |
|---|---|---|
| Node + Playwright + Chromium | Real assets from this repo (mock-ups, logo, phone) | Watch every frame |
| `Studio.renderFrame(t)` paints any moment | Closed-form springs (`Studio.spring`) | A frame is dead if nothing moves |
| Chrome frames → MP4 with ffmpeg | Basic CSS motion is banned | Every cut checked against the beat |
| 30 fps, 1080x1920 | Sound synthesized in code (oscillators + noise, zero samples) | Every scene must score 8/10 |
| | Every cut and hit locked to the beat grid | Re-render until it passes |

## Make a video

```bash
# render (about 4 minutes for 26 s) and grade it
node motion-studio/engine/render.cjs motion-studio/compositions/ehl-holiday
python3 motion-studio/engine/critique.py motion-studio/compositions/ehl-holiday

# fix a scene, then re-render only that stretch and grade again
node motion-studio/engine/render.cjs motion-studio/compositions/ehl-holiday --keep --from 8 --to 14
```

Output lands in `motion-studio/out/<name>/` (not committed): the MP4, `report.png`
(motion per frame with each scene's score), `report.json` and a contact sheet per scene.
Loop until the critic prints `OVERALL PASS`, then look at the contact sheets yourself.

For a new video, copy `compositions/ehl-holiday/`, keep `index.html` for layout and type,
and write the scenes and the soundtrack in `main.js`.

## Rules

- Every pixel is a function of time. No CSS transitions or keyframes, no easing curves,
  no `requestAnimationFrame`, no random numbers or clocks. The critic fails the piece if it finds any.
- Motion comes from springs (`snappy`, `bouncy`, `soft`, `heavy`) or constant-velocity camera drift.
- Cuts land on bar lines and pops on the 16th-note grid (`Studio.at(bar, beat, sixteenth)`),
  and the same times drive the sound, so picture and music can't drift apart.
- Real type and real assets: Instrument Serif and Manrope (in `fonts/`), left-aligned,
  never centered all-caps on a gradient. Use Corbin's real mock-ups, logo and phone number.
- TikTok size 1080x1920. Text stays inside the safe zone: y 250-1470, right edge 940.
- Corbin's rules: no cussing, never the Lord's name in vain.

## Files

- `engine/studio.js`: the runtime (beat grid, springs, scenes, synthesizer)
- `engine/render.cjs`: the headless render loop
- `engine/critique.py`: the critic
- `compositions/ehl-holiday/`: the first ad (26 s, 120 BPM)
- `fonts/`: Instrument Serif and Manrope (SIL Open Font License)
