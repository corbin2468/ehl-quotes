# Second Brain (nightly)

A scheduled Claude session runs every night at about 1:45 am Central. It works on Extreme Home Lighting LLC
(Memphis area, 901) and sends a push notification with a morning brief.

- `reminders.md`: things Corbin wants remembered. Add a line any time ("call Mrs. Lee back Friday"); the
  brief puts the ones that are due at the top, and checks them off when Corbin says they're done.
- `ideas.md`: every idea it has had, so it never repeats itself and can build on the good ones.
- `briefs/YYYY-MM-DD.md`: each night's full brief.
